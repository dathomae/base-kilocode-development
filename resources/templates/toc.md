# Templates Table of Contents

**[ero.md](ero.md)**
: Template for Epic Restraining Orders (for new EROs; pre-2026-09-16 EROs are archived)

**[prompt-driven-development-script.template.md](prompt-driven-development-script.template.md)**
: Template for creating prompt-driven development scripts, including the coordinator dispatch, escalation, and disposition conventions

**[plan.template.md](plan.template.md)**
: Template for a plan — objective, the Arc and Milestone served, settled decisions, scope, story breakdown, and the open-questions gate

**[arc.template.md](arc.template.md)**
: Template for a durable per-component arc file — component scope, milestones served (with their plans and stories), design, history, and coherence notes

**[milestone.template.md](milestone.template.md)**
: Template for a milestone file — delivered functionality, order, components, flow definitions, gap register, arcs and plans, story set, wave schedule, evaluation criteria and results, flow verification results, divergences, and the remediation log

**[stories.md](stories.md)**
: Template for individual stories (single markdown files), including the structured footprint/dependency metadata

**[design_decision.md](design_decision.md)**
: Template for capturing design decisions alongside design docs

**[epics.md](epics.md)**
: Template for epic stories (collections of related stories; suspended pending a decision)

**[subsystem-architecture.template.md](subsystem-architecture.template.md)**
: Template for a component or subsystem `README.md` — responsibilities, owned data, dependencies, seams, what it does not own, and access modality.

**[subsystem-contract.template.md](subsystem-contract.template.md)**
: Template for a component or subsystem `contract.md` — static interface (synchronous endpoints and asynchronous events), behavior (happy and non-happy paths), and an implementation map pointing into `design/`.

**[walkthrough.template.md](walkthrough.template.md)**
: Template for a story completion walkthrough — summary, what changed, deviations, decisions, verification, review/critic results, divergences, remediations, and post-mortem/lessons learned.
