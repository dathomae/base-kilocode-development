# Chronocone Planning Language (CPL) Parser - Table of Contents

## Overview

- [`README.md`](./README.md) - Project overview, build instructions, and usage examples

## Directory Structure

### Build Configuration

**[`gradle/`](./gradle/)**
: Gradle wrapper files for building the project without requiring a local Gradle installation

### Examples

**[`examples/`](./examples/)**
: Sample CPL files for testing and demonstration purposes

**[`examples/parse_and_analyze_only/`](./examples/parse_and_analyze_only/)**
: CPL examples that run through the parser and analyzer only (no synthesis)

**[`examples/parse_and_analyze_only/with_errors/`](./examples/parse_and_analyze_only/with_errors/)**
: Sample CPL files containing intentional syntax errors for testing error handling

**[`examples/parse_and_analyze_only/without_errors/`](./examples/parse_and_analyze_only/without_errors/)**
: Valid sample CPL files demonstrating correct syntax for units, concepts, measures, connectors

**[`examples/with_data/`](./examples/with_data/)**
: End-to-end CPL examples that run through the full compiler and synthesizer pipeline

**[`examples/with_data/without_errors/metrics_arithmetic/`](./examples/with_data/without_errors/metrics_arithmetic/)**
: End-to-end metrics arithmetic examples with data, expected outputs, and parquet specs

**[`examples/with_data/without_errors/metrics_conditionals/`](./examples/with_data/without_errors/metrics_conditionals/)**
: End-to-end conditional metrics examples demonstrating if/else, comparison operators, logical operators, and nested conditionals

**[`examples/parse_and_analyze_only/without_errors/metrics_time_shift/`](./examples/parse_and_analyze_only/without_errors/metrics_time_shift/)**
: Parse-and-analyze-only time shift examples demonstrating forward and backward time shifts with various configurations

**[`examples/with_data/without_errors/conditional_grain/`](./examples/with_data/without_errors/conditional_grain/)**
: End-to-end conditional grain examples with monthly data and expected outputs

**[`examples/with_data/without_errors/aggregators_basic_sum_country/`](./examples/with_data/without_errors/aggregators_basic_sum_country/)**
: Sum aggregation across country dimension (compile-only — synthesis not yet fully wired)

### Source Code

**[`src/main/antlr/`](./src/main/antlr/)**
: ANTLR4 grammar files (`.g4`) defining the Chronocone Planning Language syntax

**[`src/main/go/`](./src/main/go/)**
: Go source code for the CPL parser implementation

**[`src/main/go/analysis/`](./src/main/go/analysis/)**
: Semantic analyzer, CIL generation, symbol-table walk, type checking

**[`src/main/go/ast/`](./src/main/go/ast/)**
: Abstract Syntax Tree (AST) type definitions and their co-located tests

**[`src/main/go/calculation/`](./src/main/go/calculation/)**
: Tensor computation and ChronoconeTensor types

**[`src/main/go/cil/`](./src/main/go/cil/)**
: CIL (Chronocone Intermediate Language) transformation and code generation

**[`src/main/go/cli/`](./src/main/go/cli/)**
: CLI tools: compiler, parquet generator, parquet verifier

**[`src/main/go/connector/`](./src/main/go/connector/)**
: Connector metadata and loader generation

**[`src/main/go/io/`](./src/main/go/io/)**
: Parquet I/O helpers and tensor loading utilities

**[`src/main/go/operator/`](./src/main/go/operator/)**
: Operator definitions and operator-related logic for metric expressions

**[`src/main/go/parser/`](./src/main/go/parser/)**
: Parser implementation including listeners, main parser wrapper, and co-located tests

**[`src/main/go/parser/antlr/`](./src/main/go/parser/antlr/)**
: ANTLR-generated Go lexer and parser code (committed to version control for zero-dependency consumption)

**[`src/main/go/parsing/`](./src/main/go/parsing/)**
: Parser input definitions and metric definition structures

**[`src/main/go/symboltable/`](./src/main/go/symboltable/)**
: Symbol table stack and scope management

**[`src/main/go/synthesis/`](./src/main/go/synthesis/)**
: CPL synthesizer that generates executable Go programs

### Generated Output

**[`generated/cmd/`](./generated/cmd/)**
: Executable Go programs generated by the CPL synthesizer (one subdirectory per CPL file)

**[`shell_scripts/`](./shell_scripts/)**
: Shell utilities for compiling and running generated programs

### Standard Definitions

**[`standard_definitions/`](./standard_definitions/)**
: Built-in CPL definitions: standard concepts, units, and measures

## Test Files

Test files are co-located with the source code they test (following Go best practices):

### AST Tests (in `src/main/go/ast/`)

**[`cpl_ast_test.go`](./src/main/go/ast/cpl_ast_test.go)**
: Tests for CPLDocument and general AST functionality

**[`cpl_units_test.go`](./src/main/go/ast/cpl_units_test.go)**
: Tests for UnitDecl, Parameter, and units-related AST types

### Parser Tests (in `src/main/go/parser/`)

**[`cpl_parser_test.go`](./src/main/go/parser/cpl_parser_test.go)**
: General parser tests including empty documents and multiple sections

**[`cpl_parser_units_test.go`](./src/main/go/parser/cpl_parser_units_test.go)**
: Tests specifically for parsing unit declarations

**[`cpl_parser_examples_test.go`](./src/main/go/parser/cpl_parser_examples_test.go)**
: Integration tests using example CPL files from the examples directory

**[`cpl_parser_logging_test.go`](./src/main/go/parser/cpl_parser_logging_test.go)**
: Tests for parser logging functionality with various log levels
