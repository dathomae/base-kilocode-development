## Quick Reference

### Core Objects

- **OpenAPI Object** - Root object containing the entire API description
- **Info Object** - Metadata about the API
- **Server Object** - Server connection information
- **Paths Object** - Available API endpoints
- **Components Object** - Reusable definitions

### Request/Response Objects

- **Operation Object** - Single API operation
- **Parameter Object** - Input parameters
- **Request Body Object** - Request payload
- **Responses Object** - Response definitions
- **Media Type Object** - Content type definitions

### Schema Objects

- **Schema Object** - Data structure definitions
- **Example Object** - Example values
- **Header Object** - Response headers

### Security Objects

- **Security Scheme Object** - Authentication methods
- **OAuth Flows Object** - OAuth configuration
- **Security Requirement Object** - Security requirements

### Linking Objects

- **Link Object** - Response linking
- **Callback Object** - Webhook definitions
- **Reference Object** - Component references
