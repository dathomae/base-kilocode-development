# OpenAPI Object

This is the root object of the [OpenAPI Description](overview.md#openapi-description-structure).

## Fixed Fields

In addition to the required fields, at least one of the `components`, `paths`, or `webhooks` fields MUST be present.

## Establishing the Base URI

The base URI of an OpenAPI Description (OAD) is determined according to [RFC3986] section 5.1.1, using the `$self` field if present.

If the `$self` field is absent, or is a relative reference, the base URI is determined according to [RFC3986] section 5.1.2, 5.1.3, or 5.1.4, in that order of priority.

In practice, this means:

1. If `$self` is an absolute URI, that is the base URI
2. If `$self` is a relative reference, the base URI is determined by resolving it against the retrieval URI (if available)
3. If `$self` is absent, the retrieval URI (if available) is the base URI
4. If no retrieval URI is available, a default base URI may be used

## OpenAPI Description Structure

An OpenAPI Description (OAD) uses and extends JSON Schema to describe HTTP API request and response message data structures.

An OAD is made up of one or more documents, with the primary document being the "entry document". The entry document MUST contain an OpenAPI Object, and MAY contain references to other documents that contain additional Objects.

### Document Identification

Documents containing an OpenAPI Object at the root can be identified by the `openapi` field, which MUST be present and contain a version string.

Documents containing a Schema Object at the root can be identified by the presence of JSON Schema keywords, particularly `$schema` or `$id`.

### Relative References in API Description URIs

References within an OAD use URI references, which can be:

- **Absolute URIs**: Complete URIs including scheme (e.g., `https://example.com/schemas/user.json`)
- **Relative references**: Paths relative to the base URI (e.g., `./schemas/user.json` or `#/components/schemas/User`)
- **Fragment-only references**: References to locations within the same document (e.g., `#/info`)
