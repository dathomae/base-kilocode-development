# APIs Documentation Table of Contents

This directory contains API documentation for various libraries and frameworks used in ChronoCone.

**[antlr4/](antlr4/)**
: ANTLR 4 parser generator documentation for building lexers, parsers, and language processing tools

**[fastapi/](fastapi/)**
: FastAPI framework documentation including CLI, async/await, WebSockets, and dependency injection

**[fastparquet/](fastparquet/)**
: fastparquet library for reading and writing Parquet files, used for time series data storage

**[go-arrow-parquet/](go-arrow-parquet/)**
: Go implementation of Apache Arrow for reading, writing, and interpreting Parquet files

**[excelize-v2/](excelize-v2/)**
: excelize v2 library for reading, writing, and manipulating Excel (XLSX/XLSM) files in pure Go

**[kubernetes/](kubernetes/)**
: Kubernetes documentation including kubectl installation and usage

**[mcpservers/](mcpservers/)**
: Model Context Protocol (MCP) server development guide for building tools that integrate with LLM clients

**[openapi/](openapi/)**
: OpenAPI Specification v3.2.0 documentation covering all objects, data types, serialization, and references
