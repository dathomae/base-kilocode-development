# Design

This directory captures decisions that are not general enough for architecture and, in many cases, are specific to one version of the system.

## Guidelines

- Design documents are more specific and version-dependent than architecture documents.
- Break documents into bite-sized pieces to facilitate incremental review and use by agents.
- Concepts or definitions from [`../concepts.md`](../concepts.md), [`../requirements/`](../requirements/), or [`../architecture/`](../architecture/) SHOULD NOT BE REPEATED; reference them instead.
