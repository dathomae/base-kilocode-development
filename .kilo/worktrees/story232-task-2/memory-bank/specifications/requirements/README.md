# Requirements

This directory contains requirements specifications that extend the concepts defined in [`../concepts.md`](../concepts.md). Requirements specify lower-level items such as:

- Types and general outline of UI or plugin functionality
- Reporting capabilities
- General behavior of agents
- User-perceivable behavior (data availability, authentication/authorization, performance, sandboxing)
- Metric lifecycle

## Guidelines

- Concepts or definitions from [`../concepts.md`](../concepts.md) SHOULD NOT BE REPEATED; reference them instead.
- Use terminology recognizable by a user of the system.
- Documents may be split to facilitate incremental review and use by agents.
