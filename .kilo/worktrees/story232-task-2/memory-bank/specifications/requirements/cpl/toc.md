# Chronocone Planning Language (CPL) - Table of Contents

This directory contains specifications for the Chronocone Planning Language (CPL), a domain-specific language for defining metrics, dimensions, units, connectors, and calculations in .cpl files.

**[introduction.md](introduction.md)**
: Core CPL language concepts including structure, declarations, and syntax.

**[concepts-types-units-measures-syntax.md](concepts-types-units-measures-syntax.md)**
: Specification for concepts, types, units, and measures declaration syntax.

**[metrics-syntax.md](metrics-syntax.md)**
: Specification for metrics declaration syntax and calculation logic.

**[connectors.md](connectors.md)**
: Specification for connectors that define input shapes and data sources.

**[io_specs.md](io_specs.md)**
: Specification for IO specifications that connect connectors to data sources.

**[aggregators-and-spreaders-syntax.md](aggregators-and-spreaders-syntax.md)**
: Specification for aggregators and spreaders for dimensional transformations.

**[talking-about-time.md](talking-about-time.md)**
: Discussion of time-related concepts, types, and nuances in CPL.
