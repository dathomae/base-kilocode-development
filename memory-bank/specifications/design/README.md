# Design Specifications

Design specifications capture version-specific design decisions that are not general enough for architecture. These include EROs (Epic Restraining Orders), design decision documents, and implementation-specific patterns that may evolve over time.

## Conventions

- Design documents are stored as individual markdown files
- Each file covers a specific design decision or set of related decisions
- Design decision files follow the pattern: `<design_doc>_design_decisions.md` co-located with the design document they reference
- EROs use the format: `ERONNN_<short-decision-name>.md`
- All design documents are listed in this directory's `toc.md`
