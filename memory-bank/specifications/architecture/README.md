# Architecture Specifications

Architecture specifications define the system's structural organization — how components are divided, how they communicate, what schemas they use, and what interfaces they expose. Architecture documents describe the system as it will eventually be, providing a blueprint for implementation.

## Conventions

- Architecture documents are stored as individual markdown files
- Each file covers a specific architectural concern (e.g., database design, service layout, API structure)
- Design decisions that explain _why_ an architectural choice was made belong in the `design/` directory
- All architecture documents are listed in this directory's `toc.md`
